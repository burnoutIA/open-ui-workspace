# Open UI — workspace de test

Contenu de projet (tokens, composants, gabarit, pages) qui sert à éprouver l'outil [Open UI](https://github.com/burnoutIA/open-ui) dans les conditions d'un vrai projet.

Ce dépôt se clone dans le dossier `dev/` de l'outil, qui l'ignore :

```bash
git clone https://github.com/burnoutIA/open-ui-workspace dev
```

La CI de l'outil fait de même avant son test de bout en bout.
